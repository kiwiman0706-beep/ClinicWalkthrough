# プロンプト集

コピーして、そのまま Claude に貼ってください。`〈 〉` は自分の内容に置き換えます。

## ① 初回構築 — 図面からアプリを起こす

> 図面 PDF を添付して送ります。ページが複数ある場合は「1階は◯ページ」と伝えてください。

```
このフォルダは図面ウォークスルーのキットです。GUIDE.md に手順とヘルパーの一覧、
sample/building-sample.js に書き方の見本があります。まず両方を読んでください。

添付した図面から、app/src/walkthrough.html の //<<BUILDING>> 〜 //<</BUILDING>> を
書き替えて、この建物のモデルを作ってください。

・建物：〈用途。例：内科クリニック〉
・フロア：〈1階と2階／1階のみ など〉
・図面の縮尺：〈1:50／不明ならそう書く〉

進め方は GUIDE.md のとおりに：
1. PDF をアプリ座標に変換する式を先に決めて、既知の寸法で検算した結果を見せてください
2. 壁・建具・部屋の区画を書く（開き戸の弧から扉の位置と開く向きを取ること）
3. 家具は図面に描かれているものだけ。寸法が読めないものは source に「仮寸法」と書く
4. 最後に tools/apply-pwa-patch.py を実行して app/index.html を作り直す

図面から読み取れなかったところ、仮で決めたところは、最後にまとめて教えてください。
勝手に「それっぽく」埋めずに、分からないものは分からないと言ってください。
```

## ② 間違いの指摘 — まず文章で挙げさせる

いきなり直させるより、**先に一覧にさせて**から「全部直して」と言うほうが精度が上がります。

```
できたものと図面を見比べて、違っているところを文章で全部挙げてください。
まだ直さなくていいです。ドアの位置・開き勝手、壁の有無、家具の向きを重点的に。
```

一覧を見て、

```
全部修整してください。
```

## ③ 手書きの修正メモを渡す

図面を印刷して赤ペンで直し、**スマホで撮った写真**をそのまま添付します。

```
図面に手書きで修正を入れました。読めるところを直してください。
特に〈階段の向き／ドアの種類〉を見てください。
読めなかった箇所は直す前に聞いてください。
```

Claude が使う記号の読み方（伝えておくと早い）:

| 書き方 | 意味 |
| --- | --- |
| 扉の弧に × | 引戸に変更 |
| 壁に × ＋「壁不要」 | その壁を削除 |
| 「ここはカベ」 | 壁を戻す／追加 |
| 矢印 | その向きに移動・回転 |

## ④ 内装を詰める

```
〈待合室〉の壁を〈やわらかい緑〉、床を〈濃い木目〉にして、腰壁を〈900mm〉入れてください。
その部屋だけです。ほかの部屋は今のままで。
```

```
内装の参考写真を〈n〉枚送ります。この雰囲気の配色プリセットを追加してください。
```

**アプリ側で自分で色を触ってから固定する場合**（こちらが速いです）:

1. アプリの設定パネル → 設定の受け渡し → 「変更点をコピー」
2. その文字列を Claude に貼って:

```
アプリで調整した設定です。既定値として取り込んでください。

〈ここに貼る〉
```

## ⑤ 検証させる

```

エラーが出ないこと、家具が壁や他の家具と重なっていないこと、
どの部屋にも歩いて到達できることを確認して、結果を報告してください。
```

## うまく行かせるコツ

* **一度に欲張らない。** 「1階の壁と建具だけ先に」のように区切ると精度が上がります。
* **「だいたい合ってる」で流さない。** 気づいた違和感はその場で言ってください。
  後の修正ほど、他の部分を巻き込んで壊れやすくなります。
* **図面よりアプリを基準にする。** 一度起こしたら「アプリのここが違う」と言うほうが速いです。
  最初にそう宣言しておくと Claude が図面を読み直さなくなります。
* **寸法の根拠を残させる。** 家具の `source` に「図面の 1,900 × 600」「仮寸法」などを
  書かせておくと、後で何が確かで何が推測か分かります。
* **検証を毎回させる。** ⑤ を修正のたびに回すと、壁を消して床が抜けたような事故が防げます。
