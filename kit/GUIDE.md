## 0. 座標系

* 平面の原点は**左上**。X は右、Z（アプリでは Y と表示）は下。単位はメートル。
* 建物の大きさは `const PLAN=[幅, 奥行];` で宣言します。
* 高さは Y。床が 0、天井が 2.6。壁の厚みは 0.10 が既定。

## 1. PDF をアプリ座標に載せる（ここが肝）

### 1-1. 変換式を決める

縮尺 1:50 なら 1pt = 25.4/72×50 = **17.637 mm**。PDF のページ座標 (px, py) から:

```
appX = (px - X0) * K        K = 0.017637   （1:50 のとき）
appZ = (py - Y0) * K
```

ページが回転している図面があります。`page.rotation` が 0 でないとき、`get_drawings()`
は**回転前**の座標を返す一方 `get_pixmap()` は回転後を使うので、`page.set_rotation(0)`
してから扱うと食い違いません。回転 90°なら軸が入れ替わるので式は

```
appX = (Y0 - py) * K
appZ = (px - X0) * K
```

のような形になります。

### 1-2. 必ず検算する

X0 / Y0 は目分量で置いて、**図面に書いてある寸法**で確かめます。

* 通り芯の間隔（2,500 や 3,750 など）が式を通して同じ値になるか
* 外形が寸法線どおり（例：9,000 × 11,000）になるか
* 柱の位置が両端で合うか

2 か所以上で合うまで X0 / Y0 を動かします。**ここを妥協すると後の全部がずれます。**

### 1-3. 目で見て確かめる

アプリ座標のまま画像に焼いて、1m 方眼を重ねると読み取りが一気に楽になります。

```python
import pymupdf
K, X0, Y0, S, M = 0.017637, 150, 110, 110.0, 50.0   # S=px/m, M=余白
pg = doc[0]; pg.set_rotation(0)
mat = pymupdf.Matrix(K*S, 0, 0, K*S, -X0*K*S + M, -Y0*K*S + M)
pg.get_pixmap(matrix=mat, colorspace=pymupdf.csRGB, alpha=False).save('grid.png')
# あとは PIL で S px ごとに線を引いて番号を振る
```

### 1-4. 壁だけ抜き出す

床のハッチングに埋もれるので、**線の太さで絞る**のが有効です。

```python
for d in pg.get_drawings():
    if (d.get('width') or 0) < 0.7:   # 細い線は床パターンや寸法線
        continue
    ...
```

軸に平行な線だけ残して、同じ座標のものをまとめると壁の一覧になります。

### 1-5. 開き戸は弧で決まる

建具は `get_drawings()` の `'c'`（ベジエ）として出てきます。四分円の**中心が丁番**、
**半径が扉の幅**です。ここから位置・幅・開く向きが正確に取れます。推測しないこと。

引戸には弧がありません。壁の中に薄い長方形が 1〜2 枚あるのが引戸です。

## 2. ヘルパー一覧

`//<<BUILDING>>` の中で使えるものです。

### 床と壁

| 書き方 | 意味 |
| --- | --- |
| `floor(x0,z0,x1,z1)` | 床。**歩ける範囲でもある**ので、部屋ごとに敷く |
| `wall(x,z,w,d)` | 壁ブロック。厚み 0.10 が基本 |
| `wallX(z, x0, x1, 建具)` | Z 一定の壁（東西方向）。建具は開口の配列 |
| `wallZ(x, z0, z1, 建具)` | X 一定の壁（南北方向） |
| `pillar(x,z,一辺)` | 角柱 |
| `post(cx,cz,直径)` | 丸柱 |
| `diagWall([x0,z0],[x1,z1],厚み)` | 斜めの壁 |
| `box(x,y,z,w,h,d,'#rrggbb')` | 任意の箱（階段の踏面など） |
| `ceilingPlane(高さ, 多角形)` / `roomCeilings(高さ)` | 天井と、部屋別の天井色 |

建具の書き方は `[開口の始点, 幅, 種類, 向き]`:

* 種類 … `'hinge'`（開き戸）／`'slide'`（引戸）／`'shut'`（開かない）
* 向き … `1` / `-1` で開く側が変わる

```js
wallX(3.6, .10, 8.9, [[.60,.85,'hinge',-1], [3.55,.85,'hinge',-1]]);
wallZ(5.2, 4.6, 9.5, [[7.10,.80,'hinge',1], [8.80,.85,'slide']]);
```

### 家具

```js
make(名前, 種類, x, z, 幅, 奥行, 高さ, 回転=0, 出典='仮寸法')
```

種類は `desk, chair, bench, bed, toilet, stool, cabinet, ldesk, mri, xray, sink, urinal`。
回転は 0/90/180/270（任意角度も可）。**x,z は回転後も左上の角**です。

`出典` には「図面の 1,900 × 600」「仮寸法」のように根拠を書きます。アプリ上に表示され、
後から何が確かで何が推測か分かります。

### 部屋の区画

```js
const zones={ '1':[ ['待合室', x0,z0,x1,z1], ... ] };
```

* 点が**最初に**含まれた矩形の部屋になります。**入れ子の部屋は先に**書いてください
  （大部屋の中のトイレなど）。
* 矩形は `floor()` の区画に合わせます。壁面から 70mm 外側を見て隣室を判定しているので、
  ずれていると壁の色が隣の部屋のものになります。

### そのほか宣言するもの

| 名前 | 内容 |
| --- | --- |
| `PLAN` | `[幅, 奥行]`（m） |
| `scenes` | フロア ID → その 3D を描く関数。`{'1':scene1,'2':scene2}` |
| `chamfered()` / `chamferDepth()` / `chamferPlan` | 隅切りがある建物用。無ければ `()=>false` / `()=>1` / `null` |
| `roomLabels` | 平面図に出す `[x, z, '名前']` |
| `roomStops` | 部屋ジャンプ `['名前', 立つx, 立つz, 見るx?, 見るz?]` |
| `viewpoints` | 視点チップの `labels` と `spots`（5 つ固定）。玄関のガラスがある階は `entrance:true` |
| `layouts` | フロアごとの家具配列 |

## 3. 検証

直したら毎回これを回してください。

* 全フロア × 全モード × 全視点 × 全部屋ジャンプでエラーが出ないこと
* 平面図で家具に「はみ出し」「重なり」の警告が出ていないこと
* 玄関から**すべての部屋に歩いて到達できる**こと（壁を足したときの事故防止）
* 壁を削ったり短くしたあとは、**床が抜けていないか**（`floor()` の敷き直し忘れ）

Playwright があるなら自動化できます。無ければ手で一通り触ってください。

## 4. やりがちな失敗

* **壁を消したら床も消えた**／逆に、壁を短くしたら 100mm の隙間が残った
* **開き戸の向きを推測した** … 弧の中心を見れば分かります
* **図面の「外壁側」を取り違えた** … どの面か曖昧なときは聞くこと
* **家具を人が立てない位置に置いた** … 視点の初期位置を塞ぐと「歩けない」になります
* **zones の矩形が floor() とずれている** … 壁の色が隣の部屋のものになります
