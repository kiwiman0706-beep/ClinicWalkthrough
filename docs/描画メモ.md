# 描画のしくみ

3Dの描き方は2通りあります。**形はどちらも同じ** `faces`（図面から起こした寸法）で、
違うのは光と質感だけです。

## 既定：自前のWebGL

単一ファイル・依存ゼロ・オフライン。フラグメントシェーダーで、

* 床の木目／タイルの procedural なムラ
* 近い順16個の遮蔽物（家具＋壁）からの柔らかい接地影
* 壁の足元と天井際の AO、床から1.6mあたりのわずかな照り返し
* **下り天井のスリットの間接照明**（`coves` に登録したラインからの距離で減衰）
* 仕上げに軽い彩度・コントラスト補正

これが常用です。軽くて、どの端末でも同じように出ます。

## 任意：高画質ビュー（three.js）

パネル「見え方」の**「高画質で描画（重め）」**で、別キャンバスに切り替わります。

* `RoomEnvironment` を環境光（IBL）に。影の側が黒く潰れなくなります
* 下り天井のスリットに**実際の点光源**を並べる（3500K相当）
* ガラス面側からの昼光を**影付き**で
* ACES のトーンマッピングと sRGB 出力、物理ベースのマテリアル

実装は `hq.js`、three.js は `vendor/three.min.js`（作り直し方は `vendor/README.md`）。
サービスワーカーがどちらもプリキャッシュするので、**オフラインでも高画質ビューは動きます**。
読み込みに失敗した場合はトグル自体が出ず、既定の描画のまま動きます。

### 実テクスチャ（2026-11-07）

メーカー公式のスウォッチを `textures/` に入れて、高画質ビューで貼っています。
**面の色から品番を引く**方式です（仕上げは `designScheme` が色で決めるので、色が品番の
代わりになる）。対応表は `hq.js` の `TEX`、出典と寸法は `textures/SOURCES.csv`。

UVはワールド座標のボックス投影。建物が軸に平行なので、これでタイルが実寸どおりに並びます。
スケールの根拠と仮定は `textures/README.md` を参照（床シートとクロスは**画像幅＝製品幅**と
仮定しています。メーカーページに柄リピートの記載が無いため）。

テクスチャは非同期で読むので、読み終わりに `clinic-hq-dirty` を投げて描き直しています。
これが無いと、読み込み前に描かれた面が黒く残ります。

### まだやっていないこと

* **ダウンライトを置いていません**。照明プランに位置があり、器具リストに
  D1 `XD057527WM`（17W/3500K/1350lm/配光50°）、D2 `AD58334`（10.8W/3500K/1025lm/拡散）、
  D3 `AD58266`（6.5W/3500K/685lm/広角）、D4 `AD58310`（18.3W/5000K/1940lm）などが
  載っているので、そのまま置けます。いちばん効く次の一手。
* SSAO などのポストエフェクト。入れると入隅が締まります。
* 法線マップ（エコカラットの凹凸、クロスのエンボス）。いまはカラーのみ。
* **既定の描画にはテクスチャを入れていません**。procedural のままです。
* 薄板が壁に密着している箇所でZファイティングが残ります（`polygonOffset` で軽減済み）。
