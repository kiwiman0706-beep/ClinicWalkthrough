# 描画のしくみ

3Dの描き方は2通りあります。**形はどちらも同じ** `faces`（図面から起こした寸法）で、
違うのは光と質感だけです。

## 既定：自前のWebGL

単一ファイル・依存ゼロ・オフライン。フラグメントシェーダーで、

* 床の木目／タイルの procedural なムラ
* 近い順16個の遮蔽物（家具＋壁）からの柔らかい接地影
* 壁の足元と天井際の AO、床から1.6mあたりのわずかな照り返し
* **下り天井のスリットの間接照明**（`coves` に登録したラインからの距離で減衰）
* 仕上げに軽い彩度・コントラスト補正

これが常用です。軽くて、どの端末でも同じように出ます。

## 任意：高画質ビュー（three.js）

パネル「見え方」の**「高画質で描画（重め）」**で、別キャンバスに切り替わります。

* `RoomEnvironment` を環境光（IBL）に。影の側が黒く潰れなくなります
* 下り天井のスリットに**実際の点光源**を並べる（3500K相当）
* ガラス面側からの昼光を**影付き**で
* ACES のトーンマッピングと sRGB 出力、物理ベースのマテリアル

実装は `hq.js`、three.js は `vendor/three.min.js`（作り直し方は `vendor/README.md`）。
サービスワーカーがどちらもプリキャッシュするので、**オフラインでも高画質ビューは動きます**。
読み込みに失敗した場合はトグル自体が出ず、既定の描画のまま動きます。

### 実テクスチャ（2026-11-07）

メーカー公式のスウォッチを `textures/` に入れて、高画質ビューで貼っています。
**面の色から品番を引く**方式です（仕上げは `designScheme` が色で決めるので、色が品番の
代わりになる）。対応表は `hq.js` の `TEX`、出典と寸法は `textures/SOURCES.csv`。

UVはワールド座標のボックス投影。建物が軸に平行なので、これでタイルが実寸どおりに並びます。
スケールの根拠と仮定は `textures/README.md` を参照（床シートとクロスは**画像幅＝製品幅**と
仮定しています。メーカーページに柄リピートの記載が無いため）。

テクスチャは非同期で読みます。**読み終わってから `material.map` に差し**、そのとき
`clinic-hq-dirty` を投げて描き直しています。先に map を入れてしまうと、three.js が
未読込のテクスチャを黒い 1x1 で代用するため、読み終わるまで面が真っ黒になります
（画面は必要なときしか描かないので、数秒そのまま残ります）。読み込み中は品番の
代表色でベタ塗りし、画像が来たら `color` を白に戻して画像だけにしています。

### ダウンライト（2026-11-07）

電気設備図から**1階の28灯＋ベースライト8本**を拾いました。位置は `lamps` / `lampLines`、
器具の諸元（光束・色温度・配光半角）は `LAMP`。既定の描画では天井の器具として円盤を描き、
高画質ビューでは実際の `SpotLight` になります。**2階は電気設備図を受け取っていないので空**です。

* 強さは光束から。スポットライトの単位はカンデラなので `lm / 立体角`。
  立体角は配光半角から `2π(1-cosθ)`。そこに見た目合わせの係数 0.14 を掛けています
  （厳密な測光ではありません）。
* 1階だけで45灯あるので、**全部をシーンに入れると携帯では動きません**。灯具は10個の
  プールにして、描画のたびにカメラに近いものへ割り当て直しています。見えていない部屋の
  灯りは画に出ないので、これで足ります。
* 器具の発光面（`#fffaf0`）は下を向いていて上から光が当たらず、ふつうに塗ると暗く沈みます。
  高画質ビューでは**自己発光**にして、点灯している器具として見えるようにしています。
* 相互反射を計算していないので、下り天井の裏や棚の下が灰色に沈みます。真上を向いた
  平行光（`bounce`）を1本入れて、床からの照り返しの代わりにしています。

落とし穴を2つ踏みました。記録しておきます。

1. `build()` が `lights` を空にするのに、灯具プールは初回しか作らないので、**2回目以降の
   再構築で灯具がシーンから外れ**、ダウンライトが一切効いていませんでした。毎回入れ直します。
2. その調査中、「光源が多すぎて環境光が死ぬ」と誤診しました。実際は上のテクスチャの
   黒落ちで、**撮影が読み込み完了より早かっただけ**です。光源の数とは無関係でした。

### まだやっていないこと

* **2階のダウンライト**。電気設備図が来たら1階と同じ要領で拾えます。
* SSAO などのポストエフェクト。入れると入隅が締まります。
* 法線マップ（エコカラットの凹凸、クロスのエンボス）。いまはカラーのみ。
* **既定の描画にはテクスチャを入れていません**。procedural のままです。
* 薄板が壁に密着している箇所でZファイティングが残ります（`polygonOffset` で軽減済み）。
