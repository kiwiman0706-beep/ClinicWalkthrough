# 完成イメージ（パース）の生成メモ

開院前サイト・求人ページ用の 1F 完成イメージを、画像生成AI（Gemini / ChatGPT など）で
作るための下絵とプロンプトです。色は `図面照合メモ.md` の「1F 内装マテリアル」と同じ、
設計図書 2026-11-04 のスウォッチ実測値です。

## いちばん速いやり方（このセッションから直接生成）

環境のネットワークシークレットに `generativelanguage.googleapis.com` を
**ヘッダー名 `x-goog-api-key`／プレフィックス空**で登録してあれば、そのまま回せます。
（`Authorization: Bearer` では Gemini のネイティブAPIは 401 になります。）

```
python3 -m http.server 8099 &                   # リポジトリのルートで
python3 tools/make-refs.py refs/                # 下絵と色見本
python3 tools/gen-renders.py refs/ renders/     # 4カット生成
python3 tools/gen-renders.py refs/ renders/ hero staff   # カット指定も可
```

モデルは `gemini-3-pro-image`。プロンプト本文は `tools/gen-renders.py` にも
同じものが入っています（**片方だけ直すとズレるので両方そろえてください**）。
手元のPCで動かすときは `GEMINI_API_KEY` を環境変数に入れてください。

## 注意

* これは**完成イメージ（CG）**です。実際の写真ではないので、サイトに載せるときは
  「完成イメージ」「イメージ図」と明記してください。
* 生成された人物は実在のスタッフではありません。求人ページで使うなら、
  顔がはっきり写るカットは避けるか、実際のスタッフ写真に差し替えるのが安全です。
* サインや院名を画像内に生成させると必ず崩れた文字になります。文字は後から
  デザイン側で載せてください（プロンプトで文字を禁止しているのはそのためです）。

## カット構成（クリニックサイトの定番を調べたうえでの提案）

デザイン性の高いクリニックサイトと、医療系Web制作会社の撮影ガイドの傾向を調べた結果です
（このセッションからは直接ブラウズできないため、Geminiの検索グラウンディング経由で確認）。

**分かったこと**

* カメラは**アイレベル〜やや低め**。俯瞰は「監視カメラ感・冷たい印象」で避けられる。
* **広角が圧倒的**。日本のクリニックは待合が狭いので、広角で明るく広く見せるのが定石。
  標準レンズは人物に寄るときだけ。
* カウンターは**斜め45度が主流**。真正面は「壁・対峙」の圧迫感が出る。
* スタッフは**1〜2名**。笑顔の顔出しが王道だが、**横顔・手元で個人を特定しにくくする例が増加**。
  生成画像は実在しない人物なので、こちらを採る。
* **受付背面のロゴサイン壁の寄りカットは定番**。ファーストビューや「当院について」で使われる。
* 院内紹介＝**空間が主役・無人**／採用＝**人が主役・動きのある絵**。
* 避けるもの：患者の写り込み、画面やカルテなど個人情報、雑然、過度な加工。
* 定番セットは**10〜15カット**（外観2-3／受付待合2-3／診察室設備2-3／人物4-5）。

**それを踏まえたカット**（`tools/gen-renders.py` の `CUTS`）

| 名前 | 下絵 | 比率 | 用途 |
| --- | --- | --- | --- |
| `hero` | B（斜め45度・広角・FL+1,450） | 16:9 | トップのメインビジュアル。左上に見出し空き |
| `sign` | F（標準レンズで寄り） | 3:2 | ロゴサイン壁。ファーストビュー／「当院について」 |
| `port` | C | 4:5 | 受付まわり。SNS・縦組み |
| `wait` | A | 16:9 | 待合。院内紹介 |
| `entry` | D | 16:9 | 入ってすぐの視線。院内紹介の1枚目 |
| `corr` | G | 4:5 | 診察室へ向かう廊下 |
| `exam` | H | 16:9 | 診察室1（②ACのグリーン） |
| `staff` | B＋人物2名 | 16:9 | 採用。顔は判別不可 |
| `work` | E（スタッフ側から街側） | 16:9 | 採用。働く背中 |

出力は 2K（2752×1536 など）。外観・院長ポートレート・実際の診療風景は
3Dから作れないので、実写で押さえてください。

## ロゴの入れ方

**生成AIにロゴや文字を描かせない。**必ず崩れます。プレートは無地で出させて、
あとから本物のSVGを合成します。

1. ロゴSVGをブラウザで透過PNGに起こす（2つのロックアップが入っているので、
   縦組みと横組みに切り分ける。プレートが横長なので縦組みの方が収まる）
2. 生成画像でプレートの4隅のピクセル座標を測る
3. `python3 tools/place-logo.py <生成画像> <ロゴPNG> <出力> "x0,y0;x1,y1;x2,y2;x3,y3"`

サイン自体は 3D にも入れてあります（`wallSign()`／①ACの壁の中央、FL+1,750、W900×H300、
壁から25mm浮かせてバックライト）。展開図A面の「サイン」の位置に合わせています。
