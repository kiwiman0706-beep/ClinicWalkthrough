# 図面との照合メモ

`src/clinicwalkthrough.html` の 3D モデルを、設計図（`plan05.1F260902.pdf` / `plan05_2F_260902.pdf`、
いずれも 1/60・A3）と突き合わせて直した内容の記録です。ChatGPT で新しい版を作ったときに
同じ間違いが戻ってきていないか、ここを見て確認してください。

## 座標系

アプリは 1F・2F とも 10.8 m（X）× 12.5 m（Y）のグリッドで、原点は平面図の左上。単位はメートル。

図面の PDF 座標（pt）からアプリ座標（m）への換算は次のとおりです（1 pt = 21.172 mm）。

| | 換算式 |
| --- | --- |
| 1F（縦置きの図面。アプリとは 90° 回転している） | `appX = (py − 184.1) × 0.021172`<br>`appY = (12500 − (px − 136.9) × 21.172) ÷ 1000` |
| 2F（アプリと同じ向き） | `appX = (px − 305.8) × 0.021172`<br>`appY = (py − 110.7) × 0.021172` |

開き戸は図面に開き勝手の円弧（PDF のベジェ曲線）が描かれているので、そこから位置・幅・
開き勝手を正確に読み取れます。引戸は円弧がないため、壁の開口を目視で計測しています。

## 意図的に図面と変えているところ

**バックヤード 1・バックヤード 2・更衣室の扉**は、図面には開口が描かれていません（収納なので
省略されていると思われます）。そのまま再現すると 3D で入れない部屋になるため、通行用の扉を
残しています。実際に建具が付かないなら削除してください。

## 未照合の項目

* 壁の高さ、天井、建具の高さ（すべて仮設定）
* MRI 装置・X 線装置の外形（機器図と未照合）
* 2F 機械室の床上げ（FL+200）
* 家具の高さ全般
