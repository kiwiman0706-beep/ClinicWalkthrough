# 図面との照合メモ

`src/clinicwalkthrough.html` の 3D モデルを、設計図（`plan05.1F260902.pdf` / `plan05_2F_260902.pdf`、
いずれも 1/60・A3）と突き合わせて直した内容の記録です。ChatGPT で新しい版を作ったときに
同じ間違いが戻ってきていないか、ここを見て確認してください。

## 座標系

アプリは 1F・2F とも 10.8 m（X）× 12.5 m（Y）のグリッドで、原点は平面図の左上。単位はメートル。

図面の PDF 座標（pt）からアプリ座標（m）への換算は次のとおりです（1 pt = 21.172 mm）。

| | 換算式 |
| --- | --- |
| 1F（縦置きの図面。アプリとは 90° 回転している） | `appX = (py − 184.1) × 0.021172`<br>`appY = (12500 − (px − 136.9) × 21.172) ÷ 1000` |
| 2F（アプリと同じ向き） | `appX = (px − 305.8) × 0.021172`<br>`appY = (py − 110.7) × 0.021172` |

開き戸は図面に開き勝手の円弧（PDF のベジェ曲線）が描かれているので、そこから位置・幅・
開き勝手を正確に読み取れます。引戸は円弧がないため、壁の開口を目視で計測しています。

## 旧1階（リフォーム前・2008-10-17 の平面図）を追加（2026-09-10）

`d2223f66-___.pdf`（「やえがきナンバメンタルクリニック」1階平面図 1:50）から起こし、
アプリ内では **旧1F** タブとして 3 つめのフロアにしています。

### 座標の合わせ方

PDF はページ回転 90°で、`get_drawings()` は回転前のページ座標を返します。1:50 なので
1pt = 17.637mm。次の式でアプリ座標（m）に変換しました。

```
appX = (1053.5 − page_y) × 0.017637
appY = (page_x −  157.2) × 0.017637
```

現行 1F と同じ 10.8 × 12.5 m グリッド、同じ 2,500 / 3,750 / 4,550 のスパン、同じ隅切り
（φ800 の丸柱：旧図 page(851.3, 899.1) → app(2.72, 12.24)、現行 1F の柱は (2.69, 12.18)）に
そのまま重なります。外周の 350 角柱（appX 0.08 / 10.37 × appY 0.08 / 4.07 / 9.65）も一致した
ので、`pillars()` をそのまま使い回しています。

### 割り切ったところ

* 隅切りは `diagWall()`（任意方位の壁）で描き、床は矩形の重ね合わせで近似しています。
* 開き戸のヒンジ位置は建具の描画上つねに開口の始点側になります。図面では東側ヒンジの扉
  （診察室①〜スタッフ間など）もありますが、開口の位置・幅は図面どおりです。
* スタッフルーム〜診察室③（Y=7.2 / X 8.63〜9.45）は図面の開口の読み取りが確実でないため
  引戸としています。
* 南西の庇下（外部・300角タイル）は歩けるようにしてあります。

## 部屋ごとの仕上げ（2026-09-10）

`zones` に各フロアの部屋を矩形で持たせ、点がどの部屋に入るかで仕上げを決めています。
矩形はシーンの `floor()` の区画に合わせてあるので、壁面から 70mm 外側を見れば必ず隣室の
区画に当たります。内側に入れ子になる部屋（職員用WC）は先に並べ、先勝ちで判定します。

* 壁は `wallBox()` が**面ごと**に色を付けます。仕切り壁は両側で別の色・別の腰壁になります。
* 腰壁は面を上下に分割して下half に木目マテリアルを当てています。丸柱・斜め壁も同じ扱い。
* 床は元々タイル単位で描いているので、タイルごとに部屋を引いて色を決めています。
* 天井は全体面を描いたうえに、個別指定のある部屋だけ 12mm 下に矩形を重ねます。
  2F はもともと天井面がなかったので追加しました。
* 腰壁の高さはフロア共通（既定 900mm）。部屋ごとは有無と色のみです。
* 斜め壁（旧1Fの患者用WC）は両側を半分の厚みで描き分けています。

## 意図的に図面と変えているところ

**バックヤード 1・バックヤード 2・更衣室の扉**は、図面には開口が描かれていません（収納なので
省略されていると思われます）。そのまま再現すると 3D で入れない部屋になるため、通行用の扉を
残しています。実際に建具が付かないなら削除してください。

## 未照合の項目

* 壁の高さ、天井、建具の高さ（すべて仮設定）
* MRI 装置・X 線装置の外形（機器図と未照合）
* 2F 機械室の床上げ（FL+200）
* 家具の高さ全般
