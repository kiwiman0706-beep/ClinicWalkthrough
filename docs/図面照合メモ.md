# 図面との照合メモ

`src/clinicwalkthrough.html` の 3D モデルを、設計図（`plan05.1F260902.pdf` / `plan05_2F_260902.pdf`、
いずれも 1/60・A3）と突き合わせて直した内容の記録です。ChatGPT で新しい版を作ったときに
同じ間違いが戻ってきていないか、ここを見て確認してください。

## 座標系

アプリは 1F・2F とも 10.8 m（X）× 12.5 m（Y）のグリッドで、原点は平面図の左上。単位はメートル。

図面の PDF 座標（pt）からアプリ座標（m）への換算は次のとおりです（1 pt = 21.172 mm）。

| | 換算式 |
| --- | --- |
| 1F（縦置きの図面。アプリとは 90° 回転している） | `appX = (py − 184.1) × 0.021172`<br>`appY = (12500 − (px − 136.9) × 21.172) ÷ 1000` |
| 2F（アプリと同じ向き） | `appX = (px − 305.8) × 0.021172`<br>`appY = (py − 110.7) × 0.021172` |

開き戸は図面に開き勝手の円弧（PDF のベジェ曲線）が描かれているので、そこから位置・幅・
開き勝手を正確に読み取れます。引戸は円弧がないため、壁の開口を目視で計測しています。

## 旧1階（リフォーム前・2008-10-17 の平面図）を追加（2026-09-10）

### 座標の合わせ方

PDF はページ回転 90°で、`get_drawings()` は回転前のページ座標を返します。1:50 なので
1pt = 17.637mm。次の式でアプリ座標（m）に変換しました。

```
appX = (1053.5 − page_y) × 0.017637
appY = (page_x −  157.2) × 0.017637
```

現行 1F と同じ 10.8 × 12.5 m グリッド、同じ 2,500 / 3,750 / 4,550 のスパン、同じ隅切り
（φ800 の丸柱：旧図 page(851.3, 899.1) → app(2.72, 12.24)、現行 1F の柱は (2.69, 12.18)）に
そのまま重なります。外周の 350 角柱（appX 0.08 / 10.37 × appY 0.08 / 4.07 / 9.65）も一致した
ので、`pillars()` をそのまま使い回しています。

### 割り切ったところ

* 隅切りは `diagWall()`（任意方位の壁）で描き、床は矩形の重ね合わせで近似しています。
* 開き戸のヒンジ位置は建具の描画上つねに開口の始点側になります。図面では東側ヒンジの扉
  （診察室①〜スタッフ間など）もありますが、開口の位置・幅は図面どおりです。
* スタッフルーム〜診察室③（Y=7.2 / X 8.63〜9.45）は図面の開口の読み取りが確実でないため
  引戸としています。
* 南西の庇下（外部・300角タイル）は歩けるようにしてあります。

## 部屋ごとの仕上げ（2026-09-10）

`zones` に各フロアの部屋を矩形で持たせ、点がどの部屋に入るかで仕上げを決めています。
矩形はシーンの `floor()` の区画に合わせてあるので、壁面から 70mm 外側を見れば必ず隣室の
区画に当たります。内側に入れ子になる部屋（職員用WC）は先に並べ、先勝ちで判定します。

* 壁は `wallBox()` が**面ごと**に色を付けます。仕切り壁は両側で別の色・別の腰壁になります。
* 腰壁は面を上下に分割して下half に木目マテリアルを当てています。丸柱・斜め壁も同じ扱い。
* 床は元々タイル単位で描いているので、タイルごとに部屋を引いて色を決めています。
* 天井は全体面を描いたうえに、個別指定のある部屋だけ 12mm 下に矩形を重ねます。
  2F はもともと天井面がなかったので追加しました。
* 腰壁の高さはフロア共通（既定 900mm）。部屋ごとは有無と色のみです。
* 斜め壁（旧1Fの患者用WC）は両側を半分の厚みで描き分けています。

## 設備図の取り込み（2026-09-17）

設計士から届いた 1F/2F の **設備図1（コンセント・弱電）** から記号を拾い、アプリに重ねました。

### 図面とアプリ座標の対応（設備図・新平面図とも 1/60・横置き）

1pt = 25.4/72×60 = **21.1667 mm**。通り芯から原点を取ります。
**原点の page_x は 1F 系と 2F 系で違います**（同じ用紙の違う位置に平面が配置されているため）。

```
1F 系： appX = (page_x − 175.8) × 0.0211667
2F 系： appX = (page_x − 305.8) × 0.0211667
共通 ： appY = (page_y − 110.7) × 0.0211667
```

検算：通り芯の page_x は 1F が 175.8 / 293.9 / 686.0、2F が 305.8 / 423.9 / 816.1。
どちらも間隔が 2,500 と 8,300（=3,750+4,550）で、y=110.7 と 701.2 の間隔が 12,500。
いずれも図面の寸法と一致します。

> **2026-09-25 の訂正**：2F の設備図を最初に取り込んだとき、1F と同じ原点（175.8）を
> 使ってしまい、2F の器具 42 点が **X 方向に +2.75m ずれて**いました。通り芯を取り直して
> 原点を 305.8 に直し、拾い直した結果（51 点）に差し替えています。抽出そのものは正しく、
> ずれていたのは図面→アプリ座標の変換だけでした。

### 記号の拾い方

* 設備記号は**すべて青**（RGB 0,0,1）で描かれているので、色で抽出できます。
* 円（ベジエ）を含む青パスの外形が **φ7.6pt ≒ 160mm → コンセント類**、
  **φ4.7pt ≒ 100mm → 弱電の○記号**。
* 種別は近くの青文字で判定（`E`→アース付、`単E`→単独アース付、`ﾘｰﾗｰ`→天井用、
  `防水`、`TV`、`LAN`/`TEL`/`HDMI` など）。大円には大円用のラベル、小円には弱電ラベルだけを
  引き当てるようにしています（隣接するラベルを取り違えるため）。
* 拾えた数：1F 51点、2F 51点。抽出結果を図面に重ねて位置が一致することを、
  **両フロアとも**目視確認済み（`tools/fx_overlay.py` が出す重ね図で確認）。

### 取付高さ

図面の凡例は「特記なき限り **H=250**」。リーラーコンセントは天井用なので 2.40 を既定にしています。
図面に `H=1600` のような注記があるものは、**一番近い記号（と、その隣に並んだ同種の記号）**に
その高さを当てています。現状そうなっているのは 1F の洗濯機用（H=1600）、2F の洗濯パン（H=1400）・
スタッフルーム（H=1600）・TVジャック2口（H=2100）です。
**防犯カメラ用など天井付けのものは図面に明示がない**ので、番号で指示を受けて個別に直します。

### 腰まわりとアクセント壁（2026-09-25 追加実装）

腰壁のある部屋の壁面は、下から **巾木 60 → 腰 → 見切り 35 → 壁** の4帯で描くようにしました。
見切りは面から 12mm 出っ張る細い部材として別に立てています（歩行の当たり判定には入れません）。
巾木と見切りの色はフロア共通の設定（`#clinic-skirt` / `#clinic-trim`）。
壁を低くした俯瞰では、腰と同じ比率で縮めています。

アクセント壁は部屋ごとに「面（n/e/s/w）＋色」で指定します。`wallBox` は面ごとに
「その面が向いている部屋」を判定しているので、その部屋から見た向きに読み替えて色を選びます
（手前が −z の面は、北側の部屋から見た**南**壁）。**腰見切りより上の帯だけ**が変わります。

**面の向きは仮です。** 展開図の A〜D 面がどの方位かは、平面図の展開記号が読み取れなかったため、
待合・心療内科診察室とも北面に置いています。パネルで選び直せます。

### まだ再現できないもの

* エコカラットの凹凸・目地（色だけを当てています）。
* 造作の見切り材の断面形状（サンメント WR339 の曲面など）。
* 展開図にだけ出てくる**アコーディオンカーテン**。平面図（09-02／09-15とも）には
  描かれていないため、位置が決められません。展開図では 2F-2 の中段（処置スペースの B〜D 面）と
  2F-3 の中段（バックヤード2まわり）に出てきます。どの壁に付くか指示をもらえれば入れられます。

## 意図的に図面と変えているところ

**バックヤード 1・バックヤード 2・更衣室の扉**は、図面には開口が描かれていません（収納なので
省略されていると思われます）。そのまま再現すると 3D で入れない部屋になるため、通行用の扉を
残しています。実際に建具が付かないなら削除してください。
