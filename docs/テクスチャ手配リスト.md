# テクスチャ手配リスト

高画質ビューに実物の質感を入れるために要るもの。**照明は不要**です
（コイズミの器具リストに型番・W数・色温度・配光角まで載っていて、位置も照明プランから拾えます）。

## 1つの材料につき、ほしいもの3点

1. **スウォッチ画像** — できるだけ大きく、**正面から、影なし、柄だけにトリミング**。
   メーカーのWEBカタログの商品画像で構いません。1000px以上あると理想。
   木目は**板1枚分がまるごと写っている**ものだと、継ぎ目なく並べやすいです。
2. **リピート寸法** — 壁紙なら「タテ○cm ヨコ○cm」、床材なら板幅・目地ピッチ。
   **これが無いとスケールが合いません**（木目が巨大になったり細かすぎたりする）。
   商品ページに必ず書いてあります。
3. **ツヤ** — マット／半ツヤ／エンボスの有無。ページの表記のままでOK。

ファイル名は**品番そのまま**（`FS4274.jpg`、`WVP8255.jpg` など）にしてもらえると、
そのまま組み込めます。
