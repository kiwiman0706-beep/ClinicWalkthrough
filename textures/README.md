# textures

メーカー公式のスウォッチ画像。**高画質ビュー（`hq.js`）だけが使います**。
既定の描画は従来どおり単色＋procedural で、ここは読み込みません。

出典・取得日・製品寸法・柄リピート・ツヤの表記は `SOURCES.csv` に残してあります。

## スケールについて（重要）

UVは `hq.js` の `TEX` に書いた「その画像が実物で何メートル分か」で決まります。
**確証のあるものと、こちらで置いた仮定が混じっています。**

* 実寸が分かっているもの … `PWT4290`（板1枚 900×150mm）、メラミン3種（公式A4表示 210×297mm）、
  エコカラット `ECP-315`（CG用アセット 3636×2424mm）
* **仮定** … 床シート `FS4274/FS4276` は画像幅＝シート幅1820mm、
  クロス `WVP*`/`DEC8296` は画像幅＝巾920mm。メーカーページに柄リピートの記載が無いためです。
  実寸が分かったら `TEX` の数値だけ直せば合います。

スウォッチはシームレス加工されていないので、`MirroredRepeatWrapping` で継ぎ目を均しています。

## 色について

テクスチャを貼った面は、**メーカー画像の色が優先**されます（仕上表のスキャンから拾った
HEXより、メーカーの画像のほうが信用できるため）。そのため、パネルで部屋の色を変えても
テクスチャのある面は変わりません。色で品番を引いている（`TEX` のキーがHEX）ので、
色を変えるとテクスチャが外れて単色に戻ります。
